### Task 3: Add-your-country contributor guide + CHANGELOG

**Files:**
- Create: `docs/national-coding-packs.md`
- Modify: `CONTRIBUTING.md` (link the guide), `CHANGELOG.md`

- [ ] **Step 1: Write `docs/national-coding-packs.md`.**

A concise guide (no code test — docs). Contents:
- **What a coding pack is:** an optional national code overlay on top of the always-on WHO ICD-10 base. `translation`-class = same codes, localized display (BNO-10, and the dental chapter of ICD-10-GM / CIM-10 / MKCH-10). `modification`-class = remapped codes (only US ICD-10-CM, DX-5).
- **Steps to add a pack** (worked example = BNO-10):
  1. Add a `CodingPack` in `src/dx/packs.ts`: `{ id, system: "<national code-system URI>", kind: "translation", displays: { <DiagnosisKey>: "<localized>" }, caseDisplays: { <CaseConditionKey>: "<localized>" } }`. For a `modification` pack, use `codes: { <key>: { code, display } }` instead of `displays`.
  2. Register it in `CODING_PACKS`.
  3. Add its option to `DIAGNOSIS_CODING_OPTIONS` in `src/SettingsModal.tsx` and an i18n label for it in `src/i18n/translations.ts` (all 12 languages).
  4. (Recommended) add a completeness + a `packCoding` test mirroring `src/dx/__tests__/packs.test.ts`.
- **The key catalogs:** tooth-level keys live in `src/dx/codes.ts` (`DX_CODES`); case-level keys in `src/dx/caseCodes.ts` (`CASE_DX_CODES`). A pack should cover every **coded** key (the two uncoded peri-implant keys emit no Condition, so they need no display).
- Note that BNO-10 codes equal WHO ICD-10 (KSH: BNO-10 = WHO 2019); a translation pack never changes the code, only the display.
