# Dental ICD-10 DX-6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in (default-OFF) SNOMED CT overlay: when enabled, FHIR Conditions carry a SNOMED coding, the DX-3a uncoded peri-implant keys finally emit a (SNOMED-only) Condition, and the DX-3b laterality bodySite gains a SNOMED qualifier.

**Architecture:** A `snomedEnabled` session flag (mirrors `diagnosisCodingPack`) threads through `FhirExportOptions.snomed` into the Condition builders, which append a SNOMED coding when the flag is on and the key has a seeded `snomed` concept. Additive; default-off keeps every export byte-identical.

**Tech Stack:** TypeScript, Vitest, React (Settings).
